# 99 — Appendix

## Purpose

The appendix consolidates supporting material across the entire spec:

- All open questions in one place (decision-needed list)
- Decision log (locked decisions with rationale)
- Statutory verification list (all `[VERIFY]` items for legal/CA review)
- CA review checklist (questions for Chartered Accountant)
- Implementation phasing recommendations
- Risk register
- Glossary cross-reference

## How to use

For implementation:
- Start with `05-implementation-phasing.md` for sprint planning
- Use `06-risk-register.md` for risk-aware planning
- Reference `01-open-questions.md` to plan tenant-config decisions
- Use `04-ca-review-checklist.md` before launch for CA validation
- `03-statutory-verify-checklist.md` for compliance team validation

For governance:
- `02-decision-log.md` records all locked-in choices for future reference
- Statutory verification ensures legal soundness
