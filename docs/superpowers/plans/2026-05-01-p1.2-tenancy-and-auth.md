# Phase 1.2 — Tenancy + Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the identity foundation: real `platform.tenants`, `entity.entities` (with PAN/TAN/PF/ESI/PT statutory regs), `iam.users`, `iam.sessions`, `iam.refresh_tokens` schemas; per-schema Postgres roles replacing the P1.1 `app_role` test workaround; argon2id password hashing; JWT auth (RS256, 15-min access + 30-day refresh) with refresh-rotation reuse-detection; NestJS tenant-context middleware that opens an RLS-scoped transaction per request from JWT claims; login + refresh + logout endpoints with hard discipline (failed-login lockout, generic error messages, httpOnly Secure SameSite=Strict cookies). Deliverable: a real human can sign up → log in → load `/v1/me` → refresh token → log out, with RLS enforced end-to-end through actual auth (not test-only role).

**Architecture:** Hexagonal IAM module (`apps/api/src/modules/iam/`) with pure-TS domain (`User`, `Session`, `RefreshToken` aggregates), Drizzle adapters in `infrastructure/persistence/`, JWT signer adapter in `infrastructure/crypto/`. Real schemas in `packages/db/src/schemas/{platform,entity,iam}.ts` replacing P1.1 demo tables. Per-schema Postgres roles (`hrms_app_iam`, `hrms_app_platform`, `hrms_app_entity`) with USAGE on their schema only — defense-in-depth that closes the test-only superuser bypass. Tenant-context middleware in `apps/api/src/modules/iam/interface/middleware/tenant-context.middleware.ts` parses the access JWT, opens an RLS-scoped transaction via `withTenantContext`, attaches the request scope.

**Tech Stack:** `@node-rs/argon2` 1.8 · `jose` 5.9 (JWT/RS256) · NestJS 10 · Drizzle 0.36 · pg 8.13 · vitest 2.1 · `@testcontainers/postgresql` 10.13.

**Reference:** [Architecture design §3 (`iam`, `entity`, `platform` modules)](../specs/2026-05-01-hrms-architecture-design.md#3--bounded-contexts-modules) · [§6.2 Per-schema roles](../specs/2026-05-01-hrms-architecture-design.md#62--schema-per-bounded-context-with-isolated-postgres-roles) · [§7.1 Authentication](../specs/2026-05-01-hrms-architecture-design.md#71--authentication) · [§5 Module hexagonal pattern](../specs/2026-05-01-hrms-architecture-design.md#5--module-internal-pattern-hexagonal).

## ⚠️ Scope: what's IN, what's deferred to P1.3

### IN P1.2

- Schemas: `platform.tenants`, `entity.entities`, `entity.statutory_registrations`, `iam.users`, `iam.sessions`, `iam.refresh_tokens` — all RLS-FORCE'd, with provenance metadata
- Per-schema Postgres roles (replaces P1.1 test-only `app_role` workaround)
- Argon2id password hashing (NIST 800-63B parameters)
- JWT auth (RS256, 15-min access, 30-day refresh stored httpOnly Secure SameSite=Strict)
- Refresh rotation with **reuse detection** (revoke session family on detected reuse)
- Failed-login lockout (5 attempts in 15 min → 30-min lock)
- Generic error messages (`auth.failed` — never reveal whether email exists)
- NestJS tenant-context middleware (parses JWT → opens RLS-scoped tx → attaches scope)
- Login / Refresh / Logout / Me endpoints with full integration tests
- ADR 0004 (custom JWT vs Better Auth)

### DEFERRED to P1.3 (RBAC + MFA)

- `iam.roles`, `iam.permissions`, `iam.role_permissions`, `iam.user_effective_permissions` materialized view
- Capability tokens (compile-time-enforced authz)

- TOTP MFA
- WebAuthn passkeys
- SMS-OTP MFA (DLT-compliant, non-admin only)
- Step-up auth for sensitive operations
- HIBP k-anonymity password check
- Device fingerprint capture
- Concurrent session limit + force-logout-all
- DPDPA consent receipts (Ed25519)
- JWKS endpoint + signing-key rotation tooling

### DEFERRED to later phases

- Tenant lifecycle state machine (Phase 4 — onboarding wizard)
- Entity lifecycle state machine (Phase 4)

- ReBAC / OpenFGA sidecar (Phase 4+)

import { z } from 'zod';
import fs from 'node:fs';

const AuthEnvSchema = z.object({
  JWT_PRIVATE_KEY_PATH: z.string().default('infra/secrets/jwt-private.dev.pem'),
  JWT_PUBLIC_KEY_PATH: z.string().default('infra/secrets/jwt-public.dev.pem'),
  JWT_ISSUER: z.string().default('hrms.local'),
  JWT_AUDIENCE: z.string().default('hrms.api'),
  ACCESS_TOKEN_TTL_SEC: z.coerce
    .number()
    .int()
    .positive()
    .default(15 * 60),
  REFRESH_TOKEN_TTL_SEC: z.coerce
    .number()
    .int()
    .positive()
    .default(30 * 24 * 60 * 60),
  LOGIN_LOCKOUT_THRESHOLD: z.coerce.number().int().positive().default(5),
  LOGIN_LOCKOUT_WINDOW_SEC: z.coerce
    .number()
    .int()
    .positive()
    .default(15 * 60),
  LOGIN_LOCKOUT_DURATION_SEC: z.coerce
    .number()
    .int()
    .positive()
    .default(30 * 60),
});

export type AuthEnv = z.infer<typeof AuthEnvSchema> & {
  privateKey: string;
  publicKey: string;
};

export function loadAuthEnv(source: Record<string, string | undefined> = process.env): AuthEnv {
  const parsed = AuthEnvSchema.parse(source);
  const privateKey = fs.readFileSync(parsed.JWT_PRIVATE_KEY_PATH, 'utf8');
  const publicKey = fs.readFileSync(parsed.JWT_PUBLIC_KEY_PATH, 'utf8');
  return { ...parsed, privateKey, publicKey };
}
```

-- 0004_platform_tenants
-- expand-contract phase: EXPAND
-- locks acquired: AccessShare on platform schema (negligible)
-- safe to run during business hours: yes
-- estimated duration: <1s

CREATE TABLE platform.tenants (
  id                          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  display_name                text NOT NULL,
  slug                        text NOT NULL UNIQUE,
  status                      text NOT NULL DEFAULT 'active'
    CHECK (status IN ('active', 'suspended', 'cancelled')),
  tier                        text NOT NULL DEFAULT 'standard'
    CHECK (tier IN ('trial', 'standard', 'enterprise')),

  -- Provenance metadata (spec §5.13)
  created_at                  timestamptz NOT NULL DEFAULT now(),
  updated_at                  timestamptz NOT NULL DEFAULT now(),
  created_by_request_id       uuid,
  created_by_release          text,
  created_by_actor_id         uuid,
  last_modified_by_request_id uuid,
  last_modified_by_release    text,
  last_modified_by_actor_id   uuid,

  _version                    integer NOT NULL DEFAULT 1,
  is_deleted                  boolean NOT NULL DEFAULT false
);

CREATE UNIQUE INDEX tenants_slug_unique ON platform.tenants (slug) WHERE is_deleted = false;

ALTER TABLE platform.tenants ENABLE ROW LEVEL SECURITY;
ALTER TABLE platform.tenants FORCE  ROW LEVEL SECURITY;

-- A tenant can read its own row (for tenant-admin); platform-admin queries
-- bypass RLS by connecting as a privileged role (defined in 0008).
CREATE POLICY tenant_isolation_select ON platform.tenants
  FOR SELECT
  USING (id = NULLIF(current_setting('app.tenant_id', true), '')::uuid);

-- Tenant-write requires the same isolation; platform-admin connects as
-- hrms_admin (see 0008) which has BYPASSRLS for tenant lifecycle ops.
CREATE POLICY tenant_isolation_modify ON platform.tenants
  FOR ALL
  USING       (id = NULLIF(current_setting('app.tenant_id', true), '')::uuid)
  WITH CHECK  (id = NULLIF(current_setting('app.tenant_id', true), '')::uuid);

COMMENT ON TABLE platform.tenants IS
  'Top-level customer organizations. Each row is one tenant; multiple legal entities under entity.entities link back here.';
```

import path from 'node:path';
import { afterAll, beforeAll, describe, expect, it } from 'vitest';
import { migrate } from 'drizzle-orm/node-postgres/migrator';

  let db: DbClient;

    pgInst = await startPostgres();
    db = createClient({ DATABASE_URL: pgInst.url });
    await migrate(db.drizzle, {

// apps/api/src/modules/iam/infrastructure/crypto/argon2-password-hasher.ts
import { hash as argonHash, verify as argonVerify, Algorithm } from '@node-rs/argon2';
import type { PasswordHasherPort } from '../../domain/ports/password-hasher.port';

// NIST SP 800-63B parameters for argon2id; tuned for ~250ms on a modern CPU.
const PARAMS = {
  algorithm: Algorithm.Argon2id,
  memoryCost: 64 * 1024, // 64 MiB
  timeCost: 3,
  parallelism: 4,
};

export class Argon2PasswordHasher implements PasswordHasherPort {
  async hash(plain: string): Promise<string> {
    return argonHash(plain, PARAMS);
  }

  async verify(hash: string, plain: string): Promise<boolean> {
    try {
      return await argonVerify(hash, plain);
    } catch {
      return false;
    }
  }
}

import { SignJWT, jwtVerify, importPKCS8, importSPKI, type KeyLike } from 'jose';
import type {
  AccessClaims,
  JwtSignerPort,
  SignedAccessToken,
} from '../../domain/ports/jwt-signer.port';

export interface JoseJwtSignerConfig {
  privateKey: string;
  publicKey: string;
  issuer: string;
  audience: string;
}

const ALG = 'RS256';

export class JoseJwtSigner implements JwtSignerPort {
  readonly config: JoseJwtSignerConfig;
  private privateKeyImported: KeyLike | undefined;
  private publicKeyImported: KeyLike | undefined;

  constructor(config: JoseJwtSignerConfig) {
    this.config = config;
  }

  private async getPrivateKey(): Promise<KeyLike> {
    if (this.privateKeyImported === undefined) {
      this.privateKeyImported = await importPKCS8(this.config.privateKey, ALG);
    }
    return this.privateKeyImported;
  }

  private async getPublicKey(): Promise<KeyLike> {
    if (this.publicKeyImported === undefined) {
      this.publicKeyImported = await importSPKI(this.config.publicKey, ALG);
    }
    return this.publicKeyImported;
  }

  async signAccess(claims: AccessClaims, ttlSec: number): Promise<SignedAccessToken> {
    const key = await this.getPrivateKey();
    const expiresAt = new Date(Date.now() + ttlSec * 1000);
    const jwt = await new SignJWT({
      tenantId: claims.tenantId,
      userId: claims.userId,
      sessionId: claims.sessionId,
      actorType: claims.actorType,
      ...(claims.correlationId !== undefined ? { correlationId: claims.correlationId } : {}),
    })
      .setProtectedHeader({ alg: ALG, typ: 'JWT' })
      .setIssuedAt()
      .setIssuer(this.config.issuer)
      .setAudience(this.config.audience)
      .setSubject(claims.userId)
      .setExpirationTime(Math.floor(expiresAt.getTime() / 1000))
      .sign(key);

    return { jwt, expiresAt };
  }

  async verifyAccess(jwt: string): Promise<AccessClaims> {
    const key = await this.getPublicKey();
    const { payload } = await jwtVerify(jwt, key, {
      issuer: this.config.issuer,
      audience: this.config.audience,
      algorithms: [ALG],
    });

    if (
      typeof payload['tenantId'] !== 'string' ||
      typeof payload['userId'] !== 'string' ||
      typeof payload['sessionId'] !== 'string' ||
      typeof payload['actorType'] !== 'string'
    ) {
      throw new Error('JWT missing required claims (tenantId/userId/sessionId/actorType)');
    }

    const actorType = payload['actorType'];
    if (
      actorType !== 'user' &&
      actorType !== 'system' &&
      actorType !== 'integration' &&
      actorType !== 'job'
    ) {
      throw new Error(`JWT actorType has invalid value: ${actorType}`);
    }

    return {
      tenantId: payload['tenantId'],
      userId: payload['userId'],
      sessionId: payload['sessionId'],
      actorType,
      ...(typeof payload['correlationId'] === 'string'
        ? { correlationId: payload['correlationId'] }
        : {}),
    };
  }
}

### What the service does

1. Given a presented raw refresh token, HMAC-SHA256 it with a per-app secret.
2. Look up `iam.refresh_tokens` by `token_hash`.
3. If not found → throw `InvalidRefreshTokenError`.
4. If `consumed_at IS NOT NULL` (token already consumed once) → **revoke the entire session family** by `UPDATE iam.sessions SET status='revoked', revoked_at=now(), revoked_reason='refresh_reuse_detected' WHERE family_root_id=$1`, then throw `RefreshReuseDetectedError`.
5. Otherwise mark this token consumed, mark its session `consumed`, create a new session (parent = consumed session, same family_root), generate a new raw refresh token (32 random bytes, base64url), insert its hash into `iam.refresh_tokens`, mint an access JWT for the user, and return `{ accessJwt, newRefreshToken (raw), refreshExpiresAt, sessionId, accessExpiresAt }`.

import crypto from 'node:crypto';
import type { DbClient } from '@hrms/db';
import { withTenantContext } from '@hrms/db';
import type { JwtSignerPort } from '../ports/jwt-signer.port';
import { InvalidRefreshTokenError, RefreshReuseDetectedError } from '../errors';

export interface RefreshRotationConfig {
  hmacSecret: string;
  accessTtlSec: number;
  refreshTtlSec: number;
}

export interface RotationResult {
  accessJwt: string;
  newRefreshToken: string;
  sessionId: string;
  accessExpiresAt: Date;
  refreshExpiresAt: Date;
}

interface TokenRow {
  id: string;
  tenant_id: string;
  session_id: string;
  consumed_at: Date | null;
  expires_at: Date;
  [key: string]: unknown;
}

interface SessionRow {
  user_id: string;
  family_root_id: string;
  status: string;
  [key: string]: unknown;
}

export class RefreshRotationService {
  constructor(
    private readonly db: DbClient,
    private readonly signer: JwtSignerPort,
    private readonly config: RefreshRotationConfig,
  ) {}

  private hashToken(raw: string): Buffer {
    return crypto.createHmac('sha256', this.config.hmacSecret).update(raw).digest();
  }

  async rotate(presentedToken: string): Promise<RotationResult> {
    const tokenHash = this.hashToken(presentedToken);

    // Step 1: Locate the token row (read as superuser/admin — runs outside any
    // tenant context because we don't yet know which tenant). Production would
    // route this via a privileged "auth_resolver" role.
    const tokenLookup = await this.db.execute<TokenRow>(
      `SELECT id, tenant_id, session_id, consumed_at, expires_at
         FROM iam.refresh_tokens
        WHERE token_hash = $1
        LIMIT 1`,
      [tokenHash],
    );
    const tokenRow = tokenLookup.rows[0];
    if (tokenRow === undefined) {
      throw new InvalidRefreshTokenError();
    }
    if (tokenRow.expires_at.getTime() < Date.now()) {
      throw new InvalidRefreshTokenError();
    }

    // Step 2: Within tenant context, do the rotation work.
    return withTenantContext(this.db, { tenantId: tokenRow.tenant_id }, async (tx) => {
      await tx.query('SET LOCAL ROLE hrms_app_write');

      // Step 3: Load the session
      const sessionRes = await tx.query<SessionRow>(
        'SELECT user_id, family_root_id, status FROM iam.sessions WHERE id = $1',
        [tokenRow.session_id],
      );
      const session = sessionRes.rows[0];
      if (session === undefined) {
        throw new InvalidRefreshTokenError();
      }

      // Step 4: Reuse detection
      if (tokenRow.consumed_at !== null) {
        await tx.query(
          `UPDATE iam.sessions
                SET status = 'revoked',
                    revoked_at = now(),
                    revoked_reason = 'refresh_reuse_detected'
              WHERE family_root_id = $1`,
          [session.family_root_id],
        );
        throw new RefreshReuseDetectedError(session.family_root_id);
      }

      if (session.status !== 'active') {
        throw new InvalidRefreshTokenError();
      }

      // Step 5: Mark current consumed
      await tx.query(`UPDATE iam.refresh_tokens SET consumed_at = now() WHERE id = $1`, [
        tokenRow.id,
      ]);
      await tx.query(
        `UPDATE iam.sessions
              SET status = 'consumed', consumed_at = now()
            WHERE id = $1`,
        [tokenRow.session_id],
      );

      // Step 6: Create new session + refresh token + access JWT
      const newSessionId = crypto.randomUUID();
      const newRaw = crypto.randomBytes(32).toString('base64url');
      const newHash = this.hashToken(newRaw);
      const refreshExpiresAt = new Date(Date.now() + this.config.refreshTtlSec * 1000);

      await tx.query(
        `INSERT INTO iam.sessions
            (id, tenant_id, user_id, parent_session_id, family_root_id, expires_at)
           VALUES ($1, $2, $3, $4, $5, $6)`,
        [
          newSessionId,
          tokenRow.tenant_id,
          session.user_id,
          tokenRow.session_id,
          session.family_root_id,
          refreshExpiresAt,
        ],
      );
      await tx.query(
        `INSERT INTO iam.refresh_tokens
            (tenant_id, session_id, token_hash, expires_at)
           VALUES ($1, $2, $3, $4)`,
        [tokenRow.tenant_id, newSessionId, newHash, refreshExpiresAt],
      );

      const access = await this.signer.signAccess(
        {
          tenantId: tokenRow.tenant_id,
          userId: session.user_id,
          sessionId: newSessionId,
          actorType: 'user',
        },
        this.config.accessTtlSec,
      );

      return {
        accessJwt: access.jwt,
        newRefreshToken: newRaw,
        sessionId: newSessionId,
        accessExpiresAt: access.expiresAt,
        refreshExpiresAt,
      };
    });
  }
}

### Behavior

1. Look up user by `(tenant_id, lower(email))` where `is_deleted=false AND status='active'`.
2. If account is locked (`locked_until > now()`) → throw `AccountLockedError`. (Controller maps to 401 with code `auth.failed` — same wire response as bad-password to prevent enumeration.)
3. If user not found OR `verify(password)` fails:
   - Increment `failed_login_attempts`.
   - If new count `>= LOGIN_LOCKOUT_THRESHOLD` (env, default 5) **AND** the time since `password_changed_at` (or last successful login) is within `LOGIN_LOCKOUT_WINDOW_SEC` (default 15 min) → set `locked_until = now() + LOGIN_LOCKOUT_DURATION_SEC` (default 30 min).
   - Always do a dummy hasher.verify call when user is missing to keep response time constant (prevent user-enumeration via timing).
   - Throw `AuthFailedError`.

import crypto from 'node:crypto';
import { withTenantContext, type DbClient } from '@hrms/db';
import type { JwtSignerPort } from '../../domain/ports/jwt-signer.port';
import type { PasswordHasherPort } from '../../domain/ports/password-hasher.port';
import { AccountLockedError, AuthFailedError } from '../../domain/errors';

export interface LoginInput {
  tenantId: string;
  email: string;
  password: string;
  ipAddress?: string;
  userAgent?: string;
  correlationId?: string;
}

export interface LoginResult {
  accessJwt: string;
  refreshToken: string;
  sessionId: string;
  accessExpiresAt: Date;
  refreshExpiresAt: Date;
}

export interface LoginConfig {
  hmacSecret: string;
  accessTtlSec: number;
  refreshTtlSec: number;
  lockoutThreshold: number;
  lockoutWindowSec: number;
  lockoutDurationSec: number;
}

interface UserRow {
  id: string;
  password_hash: string;
  failed_login_attempts: number;
  locked_until: Date | null;
  password_changed_at: Date;
  status: string;
  [key: string]: unknown;
}

// Stable dummy hash to keep timing roughly constant on user-not-found path.
// argon2id format; never matches a real password.
const DUMMY_HASH =
  '$argon2id$v=19$m=65536,t=3,p=4$AAAAAAAAAAAAAAAAAAAAAA$AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA';

export class LoginHandler {
  constructor(
    private readonly db: DbClient,
    private readonly hasher: PasswordHasherPort,
    private readonly signer: JwtSignerPort,
    private readonly config: LoginConfig,
  ) {}

  private hashRefresh(raw: string): Buffer {
    return crypto.createHmac('sha256', this.config.hmacSecret).update(raw).digest();
  }

  async execute(input: LoginInput): Promise<LoginResult> {
    return withTenantContext(
      this.db,
      { tenantId: input.tenantId, correlationId: input.correlationId },
      async (tx) => {
        await tx.query('SET LOCAL ROLE hrms_app_write');

        const u = await tx.query<UserRow>(
          `SELECT id, password_hash, failed_login_attempts, locked_until,
                  password_changed_at, status
             FROM iam.users
            WHERE tenant_id = $1
              AND lower(email) = lower($2)
              AND is_deleted = false
            LIMIT 1`,
          [input.tenantId, input.email],
        );
        const user = u.rows[0];

        // Lockout check (still verify dummy below to keep timing constant)
        if (
          user !== undefined &&
          user.locked_until !== null &&
          user.locked_until.getTime() > Date.now()
        ) {
          // Constant-time penalty even when locked
          await this.hasher.verify(user.password_hash, input.password);
          throw new AccountLockedError(user.locked_until);
        }

        const ok =
          user === undefined
            ? // Always run a verify to flatten timing
              await this.hasher.verify(DUMMY_HASH, input.password)
            : await this.hasher.verify(user.password_hash, input.password);

        if (user === undefined || !ok || user.status !== 'active') {
          if (user !== undefined) {
            const newCount = user.failed_login_attempts + 1;
            const shouldLock = newCount >= this.config.lockoutThreshold;
            await tx.query(
              `UPDATE iam.users
                  SET failed_login_attempts = $1,
                      locked_until = CASE WHEN $2 THEN now() + ($3 || ' seconds')::interval ELSE locked_until END,
                      updated_at = now(),
                      _version = _version + 1
                WHERE id = $4`,
              [newCount, shouldLock, String(this.config.lockoutDurationSec), user.id],
            );
          }
          throw new AuthFailedError();
        }

        // Successful auth: reset counters, create session + refresh.
        await tx.query(
          `UPDATE iam.users
              SET failed_login_attempts = 0,
                  locked_until = NULL,
                  last_login_at = now(),
                  last_login_ip = $1,
                  updated_at = now(),
                  _version = _version + 1
            WHERE id = $2`,
          [input.ipAddress ?? null, user.id],
        );

        const sessionId = crypto.randomUUID();
        const refreshRaw = crypto.randomBytes(32).toString('base64url');
        const refreshHash = this.hashRefresh(refreshRaw);
        const refreshExpiresAt = new Date(Date.now() + this.config.refreshTtlSec * 1000);

        await tx.query(
          `INSERT INTO iam.sessions
            (id, tenant_id, user_id, family_root_id, ip_address, user_agent, expires_at)
           VALUES ($1, $2, $3, $1, $4, $5, $6)`,
          [
            sessionId,
            input.tenantId,
            user.id,
            input.ipAddress ?? null,
            input.userAgent ?? null,
            refreshExpiresAt,
          ],
        );
        await tx.query(
          `INSERT INTO iam.refresh_tokens (tenant_id, session_id, token_hash, expires_at)
           VALUES ($1, $2, $3, $4)`,
          [input.tenantId, sessionId, refreshHash, refreshExpiresAt],
        );

        const access = await this.signer.signAccess(
          {
            tenantId: input.tenantId,
            userId: user.id,
            sessionId,
            actorType: 'user',
            ...(input.correlationId !== undefined ? { correlationId: input.correlationId } : {}),
          },
          this.config.accessTtlSec,
        );

        return {
          accessJwt: access.jwt,
          refreshToken: refreshRaw,
          sessionId,
          accessExpiresAt: access.expiresAt,
          refreshExpiresAt,
        };
      },
    );
  }
}

  everywhere?: boolean;

  constructor(private readonly db: DbClient) {}

    await withTenantContext(this.db, { tenantId: input.tenantId }, async (tx) => {
      await tx.query('SET LOCAL ROLE hrms_app_write');

          'SELECT family_root_id FROM iam.sessions WHERE id = $1',

                  revoked_at = now(),
                  revoked_reason = 'user_logout_everywhere'

              AND status = 'active'`,
          [familyRootId],
        );
      } else {
        await tx.query(
          `UPDATE iam.sessions
              SET status = 'revoked',
                  revoked_at = now(),
                  revoked_reason = 'user_logout'
            WHERE id = $1
              AND status = 'active'`,
          [input.sessionId],
        );
      }
    });
  }

### Approach

NestJS's middleware contract is `(req, res, next)`. We can't simply wrap the entire request in a transaction via `next()` because `next()` is synchronous-style and the response sometimes flushes after the middleware returns. We use a different pattern: **the middleware verifies the JWT, attaches a `RequestContext` (with the `db` client), and a per-request handler-level interceptor opens the tx** inside the controller call. For P1.2 simplicity we attach a helper method `req.context.runInTenantTx(callback)` that wraps `withTenantContext` — controllers call this around any DB work.

This keeps the middleware simple (auth only) and gives controllers explicit control over their tx scope, which matches NestJS idiom.

```ts
import { Injectable, NestMiddleware, UnauthorizedException, Inject } from '@nestjs/common';
import type { Request, Response, NextFunction } from 'express';
import type { DbClient } from '@hrms/db';
import { withTenantContext } from '@hrms/db';
import type { JwtSignerPort } from '../../domain/ports/jwt-signer.port';
import type { RequestContext } from '../types/request-context';

@Injectable()
export class AuthContextMiddleware implements NestMiddleware {
  constructor(
    @Inject('JwtSignerPort') private readonly signer: JwtSignerPort,
    @Inject('DbClient') private readonly db: DbClient,
  ) {}

  async use(req: Request, res: Response, next: NextFunction): Promise<void> {
    const header = req.header('authorization');
    if (header === undefined || !header.startsWith('Bearer ')) {
      throw new UnauthorizedException({ code: 'auth.missing_bearer' });
    }
    const token = header.slice('Bearer '.length).trim();

    let claims;
    try {
      claims = await this.signer.verifyAccess(token);
    } catch {
      throw new UnauthorizedException({ code: 'auth.invalid_token' });
    }

    const ctx: RequestContext = {
      claims,
      runInTenantTx: async (callback) =>
        withTenantContext(
          this.db,
          {
            tenantId: claims.tenantId,
            actorUserId: claims.userId,
            ...(claims.correlationId !== undefined ? { correlationId: claims.correlationId } : {}),
          },
          async (tx) => {
            await tx.query('SET LOCAL ROLE hrms_app_write');
            return callback(tx);
          },
        ),
    };
    req.context = ctx;
    next();
  }
}
```

### Endpoint contract

| Method | Path                              | Auth           | Body                                            | Response                                                             |
| ------ | --------------------------------- | -------------- | ----------------------------------------------- | -------------------------------------------------------------------- |
| POST   | `/v1/auth/signup`                 | none           | `{ tenantSlug, email, password, displayName? }` | `200 { accessToken, expiresIn, sessionId }` + Set-Cookie refresh     |
| POST   | `/v1/auth/login`                  | none           | `{ tenantSlug, email, password }`               | `200 { accessToken, expiresIn, sessionId }` + Set-Cookie refresh     |
| POST   | `/v1/auth/refresh`                | refresh cookie | (none)                                          | `200 { accessToken, expiresIn, sessionId }` + new Set-Cookie refresh |
| POST   | `/v1/auth/logout?everywhere=0\|1` | Bearer         | (none)                                          | `204` + Set-Cookie clear                                             |
| GET    | `/v1/me`                          | Bearer         | (none)                                          | `200 { tenantId, userId, sessionId, email, displayName }`            |

Refresh cookie spec: `refresh=<raw>; HttpOnly; Secure; SameSite=Strict; Path=/v1/auth; Max-Age=2592000`.

In dev (`NODE_ENV !== 'production'`) the `Secure` flag is dropped so localhost HTTP works.

// apps/api/src/modules/iam/interface/http/auth.controller.ts
import {
  Body,
  Controller,
  HttpCode,
  HttpStatus,
  Inject,
  Post,
  Query,
  Req,
  Res,
  UnauthorizedException,
  BadRequestException,
} from '@nestjs/common';
import type { Request, Response } from 'express';
import { withTenantContext, type DbClient } from '@hrms/db';
import { LoginBody, SignupBody, type SignupDto, type LoginDto } from './dto/login.dto';
import type { AuthResponseDto } from './dto/auth-response.dto';
import { LoginHandler } from '../../application/commands/login.handler';
import { RefreshSessionHandler } from '../../application/commands/refresh-session.handler';
import { LogoutHandler } from '../../application/commands/logout.handler';
import {
  AccountLockedError,
  AuthFailedError,
  InvalidRefreshTokenError,
  RefreshReuseDetectedError,
} from '../../domain/errors';
import type { PasswordHasherPort } from '../../domain/ports/password-hasher.port';
import crypto from 'node:crypto';

const REFRESH_COOKIE_NAME = 'refresh';
const REFRESH_COOKIE_PATH = '/v1/auth';

function setRefreshCookie(res: Response, token: string, expiresAt: Date): void {
  const maxAgeMs = expiresAt.getTime() - Date.now();
  res.cookie(REFRESH_COOKIE_NAME, token, {
    httpOnly: true,
    secure: process.env['NODE_ENV'] === 'production',
    sameSite: 'strict',
    path: REFRESH_COOKIE_PATH,
    maxAge: Math.max(0, maxAgeMs),
  });
}

function clearRefreshCookie(res: Response): void {
  res.clearCookie(REFRESH_COOKIE_NAME, { path: REFRESH_COOKIE_PATH });
}

@Controller('v1/auth')
export class AuthController {
  constructor(
    @Inject('LoginHandler') private readonly login: LoginHandler,
    @Inject('RefreshSessionHandler') private readonly refresh: RefreshSessionHandler,
    @Inject('LogoutHandler') private readonly logout: LogoutHandler,
    @Inject('PasswordHasherPort') private readonly hasher: PasswordHasherPort,
    @Inject('DbClient') private readonly db: DbClient,
  ) {}

  @Post('signup')
  @HttpCode(HttpStatus.OK)
  async signup(
    @Body() rawBody: unknown,
    @Req() req: Request,
    @Res({ passthrough: true }) res: Response,
  ): Promise<AuthResponseDto> {
    const body: SignupDto = SignupBody.parse(rawBody);

    // Resolve tenant by slug (no tenant context yet — runs as superuser; controlled).
    const t = await this.db.execute<{ id: string }>(
      'SELECT id FROM platform.tenants WHERE slug = $1 AND is_deleted = false',
      [body.tenantSlug],
    );
    const tenantId = t.rows[0]?.id;
    if (tenantId === undefined) {
      // P1.2 simplification: auto-create tenant if missing. P1.4+ tightens this
      // behind admin-only flow.
      const newTenantId = crypto.randomUUID();
      await this.db.execute(
        `INSERT INTO platform.tenants (id, display_name, slug)
         VALUES ($1, $2, $3)`,
        [newTenantId, body.tenantSlug, body.tenantSlug],
      );
      await this.createUserAndLogin(newTenantId, body, req, res);
      return this.buildResponse(await this.tryLogin(newTenantId, body, req));
    }

    // Tenant exists: create user (RLS-scoped) then login
    const passwordHash = await this.hasher.hash(body.password);
    await withTenantContext(this.db, { tenantId }, async (tx) => {
      await tx.query('SET LOCAL ROLE hrms_app_write');
      await tx.query(
        `INSERT INTO iam.users (tenant_id, email, password_hash, display_name, status)
         VALUES ($1, $2, $3, $4, 'active')`,
        [tenantId, body.email, passwordHash, body.displayName ?? null],
      );
    });
    return this.buildResponse(await this.tryLogin(tenantId, body, req), res);
  }

  @Post('login')
  @HttpCode(HttpStatus.OK)
  async loginEndpoint(
    @Body() rawBody: unknown,
    @Req() req: Request,
    @Res({ passthrough: true }) res: Response,
  ): Promise<AuthResponseDto> {
    const body: LoginDto = LoginBody.parse(rawBody);
    const t = await this.db.execute<{ id: string }>(
      'SELECT id FROM platform.tenants WHERE slug = $1 AND is_deleted = false',
      [body.tenantSlug],
    );
    const tenantId = t.rows[0]?.id;
    if (tenantId === undefined) {
      throw new UnauthorizedException({ code: 'auth.failed' });
    }
    return this.buildResponse(await this.tryLogin(tenantId, body, req), res);
  }

  @Post('refresh')
  @HttpCode(HttpStatus.OK)
  async refreshEndpoint(
    @Req() req: Request,
    @Res({ passthrough: true }) res: Response,
  ): Promise<AuthResponseDto> {
    const cookies = (req as Request & { cookies?: Record<string, string> }).cookies ?? {};
    const refreshToken = cookies[REFRESH_COOKIE_NAME];
    if (refreshToken === undefined || refreshToken === '') {
      throw new UnauthorizedException({ code: 'auth.refresh.missing' });
    }
    try {
      const r = await this.refresh.execute({ refreshToken });
      setRefreshCookie(res, r.newRefreshToken, r.refreshExpiresAt);
      return {
        accessToken: r.accessJwt,
        expiresIn: Math.floor((r.accessExpiresAt.getTime() - Date.now()) / 1000),
        sessionId: r.sessionId,
      };
    } catch (err) {
      clearRefreshCookie(res);
      if (err instanceof RefreshReuseDetectedError) {
        throw new UnauthorizedException({ code: 'auth.refresh.reuse_detected' });
      }
      if (err instanceof InvalidRefreshTokenError) {
        throw new UnauthorizedException({ code: 'auth.refresh.invalid' });
      }
      throw err;
    }
  }

  @Post('logout')
  @HttpCode(HttpStatus.NO_CONTENT)
  async logoutEndpoint(
    @Req() req: Request,
    @Res({ passthrough: true }) res: Response,
    @Query('everywhere') everywhere?: string,
  ): Promise<void> {
    const ctx = req.context;
    if (ctx === undefined) {
      throw new UnauthorizedException({ code: 'auth.missing_bearer' });
    }
    await this.logout.execute({
      tenantId: ctx.claims.tenantId,
      sessionId: ctx.claims.sessionId,
      everywhere: everywhere === '1' || everywhere === 'true',
    });
    clearRefreshCookie(res);
  }

  private async tryLogin(
    tenantId: string,
    body: LoginDto,
    req: Request,
  ): Promise<{
    accessJwt: string;
    refreshToken: string;
    sessionId: string;
    accessExpiresAt: Date;
    refreshExpiresAt: Date;
  }> {
    try {
      return await this.login.execute({
        tenantId,
        email: body.email,
        password: body.password,
        ipAddress: req.ip,
        userAgent: req.header('user-agent') ?? undefined,
      });
    } catch (err) {
      if (err instanceof AuthFailedError || err instanceof AccountLockedError) {
        throw new UnauthorizedException({ code: 'auth.failed' });
      }
      throw err;
    }
  }

  private buildResponse(
    r: {
      accessJwt: string;
      refreshToken: string;
      sessionId: string;
      accessExpiresAt: Date;
      refreshExpiresAt: Date;
    },
    res?: Response,
  ): AuthResponseDto {
    if (res !== undefined) {
      setRefreshCookie(res, r.refreshToken, r.refreshExpiresAt);
    }
    return {
      accessToken: r.accessJwt,
      expiresIn: Math.floor((r.accessExpiresAt.getTime() - Date.now()) / 1000),
      sessionId: r.sessionId,
    };
  }
}

    expect(refresh).toBeDefined();

    refreshCookie2 = refresh!.split(';')[0]!;
    expect(refreshCookie2).not.toBe(refreshCookie1);
  });

  it('4. reusing the OLD refresh token revokes the entire family', async () => {
    const r = await request(app.getHttpServer())
      .post('/v1/auth/refresh')
      .set('Cookie', refreshCookie1);
    expect(r.status).toBe(401);
    expect(r.body).toEqual({
      statusCode: 401,
      code: 'auth.refresh.reuse_detected',
      message: 'Unauthorized',
    });

    // Even the new (legitimate) refresh now fails because family is revoked
    const r2 = await request(app.getHttpServer())
      .post('/v1/auth/refresh')
      .set('Cookie', refreshCookie2);
    expect(r2.status).toBe(401);
  });

  it('5. logout revokes the session', async () => {
    // Re-login to get a fresh session
    const login = await request(app.getHttpServer())
      .post('/v1/auth/login')
      .send({
        tenantSlug: 'acme',
        email: 'alice@acme.test',
        password: 'correct-horse-battery-staple',
      });
    expect(login.status).toBe(200);

    const r = await request(app.getHttpServer())
      .post('/v1/auth/logout')
      .set('Authorization', `Bearer ${login.body.accessToken}`);
    expect(r.status).toBe(204);
    expect(r.headers['set-cookie']).toBeDefined();
  });

  it('6. failed-login lockout: 5 wrong attempts → 6th locked', async () => {
    for (let i = 0; i < 5; i++) {
      const r = await request(app.getHttpServer())
        .post('/v1/auth/login')
        .send({ tenantSlug: 'acme', email: 'alice@acme.test', password: 'wrong' });
      expect(r.status).toBe(401);
      expect(r.body.code).toBe('auth.failed');
    }
    // 6th — even with the correct password — is locked
    const r = await request(app.getHttpServer())
      .post('/v1/auth/login')
      .send({
        tenantSlug: 'acme',
        email: 'alice@acme.test',
        password: 'correct-horse-battery-staple',
      });
    expect(r.status).toBe(401);
    expect(r.body.code).toBe('auth.failed'); // same wire code as wrong-pwd: no leak
  });

  it('7. wrong-tenant or wrong-email gives the same generic auth.failed', async () => {
    const r1 = await request(app.getHttpServer())
      .post('/v1/auth/login')
      .send({ tenantSlug: 'nonexistent', email: 'whoever@example.com', password: 'whatever' });
    expect(r1.status).toBe(401);
    expect(r1.body.code).toBe('auth.failed');
  });
});
