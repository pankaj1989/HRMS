**Spec:** [`docs/superpowers/specs/2026-05-01-p1.1.5-dep-hardening-design.md`](../specs/2026-05-01-p1.1.5-dep-hardening-design.md)

**Subagent dispatch policy:** All Agent dispatches use `model: "opus"` per project standing rule.

**No-code-change constraint:** This is a deps-only sweep. If any bump forces a code change to `apps/*` or `packages/*` source files (excluding `package.json` itself, lockfiles, and CI config), **stop and escalate**. The fallback is to downgrade to the highest version within the same minor that doesn't require code changes, and add the residual advisory to `osv-scanner.toml`.

## Failure-mode quick reference

| Symptom                                            | Action                                                                                                                                                                      |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm type` fails after a bump                     | Stop. The bump forced a code change. Downgrade to highest patch within the same minor that types clean; if none exist, add the residual to `osv-scanner.toml` and escalate. |
| `pnpm test` test count drops                       | Stop. A test was silently skipped or removed by the bump's harness change. Diff the test runner output and escalate.                                                        |
| `pnpm-lock.yaml` won't satisfy `--frozen-lockfile` | Re-run `pnpm install --no-frozen-lockfile`, then `rm -rf node_modules && pnpm install --frozen-lockfile`. If still failing, escalate.                                       |
| osv-scanner local run fails after T3               | Add `pnpm.overrides` for the lingering transitive in root `package.json`, re-run install + gates, and amend T3 commit (if not yet pushed) or append a follow-up commit.     |
| Next 15.x cannot clear `GHSA-9qr9-h5gf-34mp`       | Stop and escalate. Major bump is out of scope.                                                                                                                              |
| Application source files appear in `git status`    | Abort the task. The "no app code changes" invariant is violated. Reset and escalate.                                                                                        |
| CI fails on push despite local green               | Pull the failed job log via `gh run view <id> --log-failed`. Most likely a lockfile deduping issue or a CI-only env diff — diagnose, don't blanket-retry.                   |
