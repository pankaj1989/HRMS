## Verification gates

Run in order; all must pass before commit + push:

1. `pnpm install --no-frozen-lockfile` — lockfile updates cleanly with no peer-dep errors. After the bumps land, the rebuilt lockfile must pass `pnpm install --frozen-lockfile` from a clean cache.
2. `pnpm type` — typecheck passes across all 12 workspace packages.
3. `pnpm build` — build passes across all 12 packages.
4. `pnpm test` — full test suite passes.
5. `pnpm lint` and `pnpm format:check` — pass.
6. `pnpm dlx osv-scanner --recursive --skip-git --config=osv-scanner.toml ./` — clean except for explicitly ignored multer entries.
7. CI on PR #1 — green with `osv-scanner` step as **blocking** (`continue-on-error: false`, original behavior).

Failure handling: if a bump breaks any of gates 2–5, downgrade to the highest patch within the same minor that passes, and add the residual advisory to `osv-scanner.toml` with a tracking note. Do not silence with `continue-on-error`.
